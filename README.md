# 微信红包自动抢脚本 (macOS M4)

一个适用于 macOS 的微信全自动抢红包 Python 脚本。专门针对 Apple Silicon (M4) 芯片和 Retina 显示屏进行了优化。

## 🚀 工作原理
脚本通过高频率连续截屏，并使用 **OpenCV 多尺度模板匹配** 来检测聊天列表中的红包气泡。一旦发现红包，就会调用 `PyAutoGUI` 模拟鼠标点击，等待金色的“开”按钮出现后再次点击领取。

成功抢到一个红包后，脚本会自动退出。

## 📋 环境要求
- macOS (在 Apple Silicon M4 测试通过)
- Python 3
- 微信 macOS 桌面版

## 🛠️ 安装

1. 克隆本项目并进入目录：
```bash
# git clone <你的仓库地址>
cd "wechat pocket" # Note: directory name remains unchanged
```

2. 安装所需的 Python 依赖：
```bash
pip3 install pyautogui opencv-python Pillow mss
```

## ⚙️ 设置与使用

### 1. 授权系统权限
由于脚本需要截屏和模拟鼠标点击，你必须在 **系统设置 -> 隐私与安全性** 中为你运行脚本的终端（或 IDE）授予以下权限：
- ✅ **屏幕录制** (用于截图识别红包)
- ✅ **辅助功能** (用于模拟鼠标点击)

### 2. 截取模板图片（仅限首次运行）
因为每个人的屏幕分辨率和 UI 缩放比例不同，所以在正式运行前，你需要先截取属于你屏幕的模板图片。

```bash
python3 wechat_red_packet.py --capture
```
运行后，按照终端里的交互提示截取两张图：
1. **红包气泡**：聊天窗口中出现的红包消息。
2. **“开”按钮**：点击红包后弹出的巨大的金色圆形“开”按钮。

*注意：截图时请尽量紧贴核心视觉元素框选，避免截取到多余的背景干扰，以提高识别准确率。*

### 3. 运行脚本
打开你要抢红包的目标微信聊天窗口，确保它在屏幕上可见。然后运行：

```bash
python3 wechat_red_packet.py
```
脚本将开始监控屏幕，并在下一个红包出现时自动帮你抢到手！

## 🔧 高级配置
你可以通过传递命令行参数，或者直接修改 `wechat_red_packet.py` 顶部的全局变量来微调脚本性能：
- `--interval`: 截屏扫描间隔（默认极快，如果占用过多 CPU 可适当调大）。
- `--threshold`: OpenCV 图像匹配的置信度阈值（0~1，越靠近1越严格）。
